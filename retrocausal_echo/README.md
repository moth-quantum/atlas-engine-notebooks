# Echo Audio (`retrocausal-echo-staging`)

`retrocausal_echo_notebook.ipynb` applies a quantum-measured multi-tap delay to audio and walks through how quantum the circuit is, what inverted echoes do, the effect's impulse response, and re-rendering one measurement.

- `snare_crack.wav`, `rhodes_c4.wav`: from Moth's QEcho sample pack (synthesised, mono 24-bit / 44.1 kHz).

Family: Echo (core engine in `otoc_echo/`). The API names this engine Retrocausal Echo.
