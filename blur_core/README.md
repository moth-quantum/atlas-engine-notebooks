# Blur Core (`blur-core-staging`)

`blur_core_notebook.ipynb` runs Blur's core engine on plain grids of numbers: a 1-D spike and a 2-D ring, built in the notebook. It walks through strength, reach, axes, style and shots.

Family: Blur. Media engines: Blur Image (`blur/`), Teleblur (`telablur/`), Blur MIDI (`blur_midi/`).
