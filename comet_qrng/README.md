# Entropy Core (`comet-qrng-staging`)

`comet_qrng_notebook.ipynb` draws certified random bytes from quantum measurement (min-entropy certificate, Toeplitz extractor, CHSH Bell witness) and walks through shots, derived dice and the witness.

Family: Entropy. Media engine: Coin Toss (`coin_toss/`). The API names this engine Comet Quantum RNG.
