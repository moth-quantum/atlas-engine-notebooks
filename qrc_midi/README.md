# Reservoir MIDI (`qrc-midi-staging`)

`qrc_midi_notebook.ipynb` learns a MIDI phrase with a quantum reservoir and generates new arrangements, then walks through variation, training quality and looping.

- `phrase.mid`: an original 8-bar phrase (melody and bass, 100 bpm) made for these notebooks.

Family: Reservoir (no core engine yet). The API names this engine QRC MIDI.
