# Reservoir Audio (`qrc-audio-staging`)

`qrc_audio_notebook.ipynb` cuts a chord loop into bars, learns their order with a quantum reservoir and generates new progressions, then walks through variation, training quality and chunk length.

- `loop.wav`: 8 bars at 96 bpm (Am F C G Dm F E Am; mono, 16-bit / 44.1 kHz), built from Moth's QEcho sample pack.

Family: Reservoir. The API names this engine QRC Audio.
