# Reservoir Audio (`qrc-audio-staging`)

`qrc_audio_notebook.ipynb` cuts a loop into beats, learns their order with a quantum reservoir and generates new arrangements, then walks through variation, training quality and crossfade.

- `loop.wav`: 4 bars at 120 bpm (mono, 16-bit / 44.1 kHz), assembled from Moth's QEcho sample pack.

Family: Reservoir (no core engine yet). The API names this engine QRC Audio.
