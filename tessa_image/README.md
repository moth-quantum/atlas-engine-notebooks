# Tessa Image (`tessa-image-staging`)

`tessa_image_notebook.ipynb` sends an image through a quantum round trip with the Tessa encoder and walks through machines, range correction, distortion, encodings and shots.

- `qcat28_color.png`, `qcat28.png`: QCAT (28 × 28, colour and greyscale), pixel art by Daniel Bultrini from the Tessa paper.

Family: Tessa (no core engine yet).
