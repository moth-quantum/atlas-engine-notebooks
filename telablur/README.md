# Quantum Teleblur (`telablur-v1`)

`telablur_notebook.py` — a marimo notebook that morphs a source image into a target image and sweeps the strength.

- `outputs/telablur_notebook.ipynb` — the static notebook, with all outputs, that GitHub and Atlas render.
- `image1.png`, `image2.png` — the 256 × 256 source and target samples.
