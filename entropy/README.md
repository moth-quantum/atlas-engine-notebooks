# Entropy

| Notebook | Engine | What it does |
|---|---|---|
| `entropy_core_notebook.ipynb` | Entropy Core (`comet-qrng-staging`; the API names it Comet Quantum RNG) | Draws certified random bytes from quantum measurement (min-entropy certificate, Toeplitz extractor, CHSH Bell witness) and walks through shots, derived dice and the witness. |
| `coin_toss_notebook.ipynb` | Coin Toss (`coin-toss-v1`) | Flips a quantum coin and compares heads/tails splits as shots grow. |
