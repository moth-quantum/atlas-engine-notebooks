# Prism Shader (`entanglement-shader-staging`)

`entanglement_shader_notebook.ipynb` bakes iridescent material shaders from a quantum collision model of light in a layered stack, previews each as a lit sphere, and walks through style, interaction, layers and reflectance. Shader ZIPs are saved beside the notebook when it runs.

Family: Prism (no core engine yet). The API names this engine Entanglement Shader.
